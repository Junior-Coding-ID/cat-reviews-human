A one-line review, written by a cat about its human — for the
"Make the AI Judge Laugh: Cat Reviews Its Human" bounty on make.fun.

## Entry

> 1 star: My heated bed arrived in a magnificent cardboard villa, which housekeeping demolished while I was in it to make room for the complimentary cushion.

## How it works

Run `node main.ts` (no arguments). It writes the entry text, followed by
a newline, to `entry.txt` inside the output directory
(`MAKEFUN_OUTPUT`, defaulting to `/output`).
